# Minicurso GitHub Projects na Prática

Material do minicurso dado na Semana da Informática 2026 do IFSP Araraquara.

A ideia é simples: o grupo para de combinar tarefa no WhatsApp e passa a usar o próprio GitHub para saber quem está fazendo o quê. Este repositório, o **Mural de Caronas**, é o projeto de exemplo. As issues, o board e o PR #7 que você vê aqui foram criados durante a aula.

## Por onde começar

Siga na ordem. Cada atividade termina com um **Pronto quando**, que é o critério para saber se você terminou.

## O que você precisa

- Uma conta no GitHub
- Git instalado (`git --version` no terminal tem que responder)
- Um grupo de 2 a 5 pessoas. Dá para fazer sozinho, mas a parte de revisão de PR perde a graça.
- Para a Parte 2: o [GitHub CLI](https://cli.github.com/) e um assistente de IA com suporte a MCP. Os exemplos usam o [Claude Code](https://docs.claude.com/en/docs/claude-code/overview).
