# Mural de Caronas IFSP

Site para alunos do IFSP Araraquara combinarem carona até o campus.

Projeto de exemplo do mini curso **GitHub Projects na Prática**.

## Material do curso

O passo a passo completo, com os slides, está na pasta [`curso/`](curso/README.md):

1. [Parte 1: GitHub Projects](curso/01-github-projects.md)
2. [Parte 2: GitHub CLI e GitHub MCP](curso/02-parte-2-gh-cli-e-mcp.md)

## Como rodar

1. Clone o repositório: `git clone https://github.com/natansalvadorligabo/mural-de-caronas-ifsp.git`
2. Abra o arquivo `index.html` no navegador.

## Como contribuir

1. Pegue uma issue no board e mova para **In Progress**.
2. Crie uma branch a partir da `main`: `git switch -c tipo/descricao`
3. Abra um pull request com `Closes #N` na descrição.
